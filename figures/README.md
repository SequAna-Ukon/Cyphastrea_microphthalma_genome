## Manuscript figures

### Figure 1

Cladogram based on a simple species tree generated with the NCBI ETE v3.1.3 toolkit based on published Hexacorallian genomes (see manuscript for corresponding references).

### Figure 2

Genome size estimation plot based on k-mer distribution (k = 21) using a histogram generated by KMC (**/figures/Phar_ONT_histogram.tabular**) fed into GenomeScope 2.0 for visualization.

### Figures 3 & 4 

BlobToolKit v4.3.0 quality assessment of the *Porites harrisoni* genome assembly. Run BlobToolKit remotely on the folder **/figures/Cmic_BTK/**

```bash
conda create -n btk python=3.9
conda activate btk
pip install blobtoolkit

blobtools view --remote /figures/Cmic_BTK/
```

### Figure 5

*Cyphastrea microphthalma* mitochondrial genome assembly and annotation based on the mitochondrial genome available through GenBank as a single-contig of the *Cyphastrea microphthalma* assembly (https://www.ncbi.nlm.nih.gov/nuccore/JBMGOP000000000).
